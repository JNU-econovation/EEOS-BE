새 기능 개발 워크플로우를 시작합니다.

요구사항: $ARGUMENTS

아래 순서로 서브에이전트를 순차 호출하세요. 각 단계는 이전 단계의 산출물을 컨텍스트로 받습니다.

**워크플로우: 1→2→3→4→5→6→7**

1. **planner** 에이전트를 호출해 To-do 리스트를 작성하게 한다.
   - 완료 후 사용자 컨펌을 기다린다. 컨펌 없이 다음 단계 진행 금지.

2. **architect** 에이전트를 호출해 API 설계서와 DB 스키마를 작성하게 한다.
   - 완료 후 사용자 컨펌을 기다린다. 컨펌 없이 다음 단계 진행 금지.

3. **qa** 에이전트를 호출해 실패하는 테스트 코드를 작성하게 한다.

4. **backend-dev** 에이전트를 호출해 테스트를 통과시키는 구현 코드를 작성하게 한다.

5. **reviewer** 에이전트를 호출해 코드 리뷰를 수행하게 한다.
   - 🔴 Must Fix 항목이 있으면 개발자에게 수정을 요청하고 재리뷰한다.

6. **doc-slave** 에이전트를 호출해 문서를 작성하게 한다.

7. **doc-reviewer** 에이전트를 호출해 문서를 검토하게 한다.
   - 🔴 오류가 있으면 doc-slave에게 재작성을 요청한다.

모든 단계 완료 시: "✅ [기능명] 개발 워크플로우 완료!" 메시지를 출력한다.
